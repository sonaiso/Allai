# Formal Entities

- **ProofState**: immutable-stage logical carrier of closure facts and trace evidence.
- **Trace Event**: ordered, explainable event in constitutional progression.
- **Gate Law**: machine-checkable precondition/postcondition for each rank transition.
- **No-jump Invariant**: prohibition against skipping required closure ranks.
- **Ambiguity Outcome**: one of {resolved, suspended-with-reason}.
- **Replay Record**: deterministic reconstruction view of a trace chain.
