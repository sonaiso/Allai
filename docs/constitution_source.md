# Constitution Source (Operationalized)

This document is the project constitutional source used to derive machine-checkable closure rules.

## Constitutional precedence order (v1)
1. Foundational constitution (top-level framing and interpretation authority).
2. Domain constitutions (singular/compositional constitutions and migration bridge).
3. Machine-checkable law/specification (`specs/*.yaml`).
4. Executable enforcement (`src/**`) and tests (`tests/**`).

Interpretation flows downward by this order; executable behavior changes only when promoted into spec + code.

## Core constitutional ranks for MVP v1 (current)
1. Ingress admissibility (pre-U0).
2. Singular closure pyramid (existence, designation, possibility, identity, relational, weight, logical-classificatory, unified closure gate) under **minimum-first** rank gating.
3. Hierarchical compositional closure in khabar/insha under **minimum-first** rank gating.
4. Composition and ambiguity governance.
5. Communicative closure.
6. Proposition closure.
7. Judgement transition with trace validation and replay determinism.

## Guiding principle
Code follows constitutional order; constitutional order does not follow code convenience.

## Minimum-first codification principle
Only necessary transition conditions are mandatory at each rank.
Explanatory/analytic expansions are deferred unless explicitly promoted to gate law.
